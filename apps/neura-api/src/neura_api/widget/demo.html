NEURA widget — local harness

Not a product page. This exists so the widget can be driven against a running API without a merchant site, under the same Content-Security-Policy a merchant would be asked to apply.

Load it with a public key in the query string, which the route below turns into the embed snippet: /v1/widget/demo?key=fn_pk_test_…

The key must be origin-locked to this origin (ADR-0014 §3) or every request is refused before a model runs — which is the control working, not a misconfiguration to route around.
