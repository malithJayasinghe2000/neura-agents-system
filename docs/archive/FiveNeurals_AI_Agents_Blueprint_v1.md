**THE VISION**

FiveNeurals delivers **5 modular AI agents** that businesses can integrate individually or as a complete ecosystem. Each agent is powerful alone, but when combined, they create an intelligence network that transforms how businesses operate. Think of it like the Avengers — each hero is powerful solo, but together they're unstoppable.

**Integration Methods (3 Ways)**

**Method 1: REST API (Simplest — Any Platform)**

Any system that can make HTTP requests can integrate. This is the universal method.

POST https://api.fiveneurals.com/v1/sell/predict-intent  
Authorization: Bearer fn\_sk\_xxxxx  
Content-Type: application/json

{  
  "customer\_id": "cust\_123",  
  "session\_data": { "pages\_viewed": \[...\], "time\_on\_site": 340 }  
}

●  **Best for:** Backend integrations, legacy systems, ERPs

●  **Latency:** \~200-500ms per call

●  **Complexity:** Low

**Method 2: SDK (Easiest for Developers)**

Pre-built libraries for popular languages.

// JavaScript/Node.js SDK  
import { FiveNeurals } from '@fiveneurals/sdk';

const fn \= new FiveNeurals({ apiKey: 'fn\_sk\_xxxxx' });

// Use NEURA-SELL  
const prediction \= await fn.sell.predictIntent({  
  customerId: 'cust\_123',  
  sessionData: { pagesViewed: \[...\] }  
});

// Use NEURA-CARE  
const response \= await fn.care.handleMessage({  
  customerId: 'cust\_123',  
  message: 'Where is my order?',  
  channel: 'chat'  
});

\# Python SDK  
from fiveneurals import FiveNeurals

fn \= FiveNeurals(api\_key="fn\_sk\_xxxxx")

\# Use NEURA-MIND  
report \= fn.mind.generate\_report(  
    type="weekly\_sales",  
    date\_range=("2026-04-01", "2026-04-30")  
)

●  **Best for:** Modern web/mobile apps, SaaS platforms

●  **Languages:** JavaScript, Python, PHP, Java, Go (start with JS \+ Python)

●  **Complexity:** Very Low

**Method 3: Embeddable Widgets (No Code Needed)**

For agents with UI (SELL chat, CARE support widget).

\<\!-- Drop this in any website \--\>  
\<script src="https://cdn.fiveneurals.com/widget.js"\>\</script\>  
\<script\>  
  FiveNeurals.init({  
    apiKey: 'fn\_pk\_xxxxx',  // Public key (safe for frontend)  
    agents: \['sell', 'care'\], // Which agents to activate  
    theme: 'dark',  
    position: 'bottom-right'  
  });  
\</script\>

●  **Best for:** E-commerce websites, any website

●  **Complexity:** Zero (copy-paste)

**TECHNOLOGY STACK — HOW TO BUILD THIS**

**Core Infrastructure**

| Layer | Technology | Why |
| :---- | :---- | :---- |
| LLM Backbone | OpenAI GPT-4o \+ Anthropic Claude 4 \+ Google Gemini 2.5 | Multi-model approach — use the best model for each task. Don't lock into one provider. |
| Agent Framework | LangGraph (by LangChain) | Purpose-built for multi-agent systems with state management, tool use, and human-in-the-loop. Best framework for production agents in 2026\. |
| Workflow Automation | n8n (self-hosted) | Visual workflow builder for connecting agents to external services (email, SMS, CRMs, etc.). Great for non-code integrations. |
| Vector Database | Qdrant or Pinecone | For semantic search, knowledge bases, and RAG (Retrieval Augmented Generation). Qdrant is open-source and fast. |
| Backend API | FastAPI (Python) | High-performance async Python API. Perfect for AI workloads. |
| Real-time | WebSockets via FastAPI | For live chat, real-time notifications, streaming responses |
| Database | PostgreSQL \+ Redis | PostgreSQL for structured data, Redis for caching and session management |
| Message Queue | Redis Streams or RabbitMQ | For agent-to-agent communication (event bus) |
| Frontend Dashboard | Next.js (you already have this\!) | Client dashboard to manage agents, view analytics, configure settings |
| Hosting | AWS or Railway or Fly.io | Start with Railway for simplicity, migrate to AWS as you scale |
| Monitoring | LangSmith \+ Sentry | LangSmith for LLM observability (trace every AI decision), Sentry for error tracking |
